Notes are for your team. Discussions are shared with the client.

## Who can see a file

Each file says whether the client can see it. New files are private until you share them.

## What you can attach

Documents, spreadsheets, text files, images, archives and audio or video can be attached, up to 50 MB. Web pages (HTML), SVG images, XML files, scripts and programs are refused: they can run when opened, so attach a PDF or an ordinary image instead. The check looks at what the file actually is, not only at its name. Receipts on an expense are stricter: see the expenses help.

## Comments

Comments belong to the note, discussion or record they were written on.
